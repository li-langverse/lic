## Abstract

Swarm gap orchestration (registry ingest, backlog apply, handoffs) depends on **read APIs** that work identically in homelab, K8s org-research Jobs, and CI. This pass audits api-coverage for the `swarm_coverage` meta-goal and finds REST endpoints largely complete in `li-cursor-agents`, while MCP tooling and control-plane disk persistence leave orchestration blind spots that distort grading and block unattended gap refresh.

## Findings

### 1. Org-research Jobs lack REST parity

K8s researcher pods mount benchmarks + lic but typically **not** the ops-server. Meta-agents must use MCP or explicit file paths. Missing MCP read tools force brittle path knowledge — a coverage defect for `swarm_coverage`.

### 2. Control-plane persistence API gap

Without `state.json` and `latest-report.json`, the programmatic observer cannot expose `observer.retry_counts` or intervention history to auditors. Grade dimension `swarm_execution` reads as 100 (0 errors, 1 running sample) while orchestration self-heal is **unobservable**.

### 3. Gap ingest CLI blocked on PyYAML

```text
swarm-gap-ingest: PyYAML required (pip install pyyaml)
swarm-gap-apply-actions: PyYAML required
```

This is an **infra API contract** failure: the ingest script's dependency is not declared in the worker image. Apply artifacts can remain fresh while registry drift accumulates.

### 4. Briefing heap under-covers gap/plan agents

Scorecard recommends `gap_explorer` and `plan_verifier` when `gap_pressure` < 80; briefing heap surfaces only `ci_maintainer` and `security_auditor`. Orchestration scheduling drift reduces unattended gap reconciliation throughput.

### 5. Gap action pipeline coverage

Of 62 open gaps in the apply artifact:

| Outcome | Count | Meaning |
|---------|-------|---------|
| Backlog patched | 19 | sim/security/package backlogs updated |
| Deferred (no mapping) | 20 | master-plan + ph-db rows need issue/handoff API |
| Handoff-only | 21 | competitor/HPC gaps awaiting research lane |

## Recommendations

1. **MCP:** Add `read_ecosystem_quality_report`, `read_swarm_gap_registry`, `read_swarm_gap_actions` to `li-ecosystem-context`.
2. **Deploy:** Install `python3-yaml` (or vendored PyYAML) in org-research worker image.
3. **Briefing:** Merge scorecard `recommended_agents` into heap when dimensions below threshold.
4. **CP persistence:** Supervisor tick should write `state.json` + `latest-report.json` to durable volume shared with research Jobs (or MCP mirror).
5. **Apply script:** Map master-plan `plan_debt` gaps to `issue_planner` handoff queue instead of `deferred (no runner backlog mapping)`.

---

## Conclusion

API-coverage for `swarm_coverage` is **partial**: file mounts suffice for a homelab auditor with shell access, but **not** for unattended org-research Jobs. Closing MCP and infra dependency gaps is prerequisite for honest meta-audit without human path knowledge.
