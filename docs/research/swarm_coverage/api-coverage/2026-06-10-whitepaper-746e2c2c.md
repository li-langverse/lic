## Metric: `runs_sampled` sensitivity

The ecosystem grader's `swarm_execution` dimension weights run telemetry. When `LI_CURSOR_AGENTS_ROOT` defaults to a non-existent sibling path:

| `runs_dir` | `runs_sampled` | `swarm_execution` score | `overall_score` | `unattended_safe` |

| `/workspace/li-cursor-agents/data/runs` | 0 | 65 | 66.8 (D) | false |
| `/app/data/runs` | 1 | 100 | 75.6 (C) | true |

**Remediation:** auto-detect `/app/data/runs` in `ecosystem-quality-grade.py` (shipped this pass) + set `LI_CURSOR_AGENTS_ROOT=/app` in Job env.
