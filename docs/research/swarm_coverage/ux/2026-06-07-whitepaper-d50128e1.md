## Abstract

This whitepaper audits the **user-experience lens** of Li's swarm gap orchestration control plane. We find that orchestration UX is degraded not primarily by product UI defects, but by **control-plane observability gaps** (missing persisted state, zero run sampling) and a **blocked gap pipeline** (ingest syntax error, missing PyYAML). Studio UI wave-2 todos (`palette latency`, `GPU recovery`) remain the highest-impact product UX debt linked to the gap registry. We propose four `ui_ux` registry rows and routing via existing research goals — no new systemd plan loops.
