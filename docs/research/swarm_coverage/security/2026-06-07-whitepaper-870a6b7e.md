## Abstract

This audit evaluates whether the Li agent swarm can operate unattended from a **security** perspective while executing gap orchestration (registry ingest, backlog apply, handoffs). Grade **D** (60.9) with `unattended_safe: false` reflects failing prefights, CI debt, and incomplete CWE catalog coverage—not active agent compromise. ## Findings

### 1. CWE catalog gap (high)

- Top25 baseline: 25 CWE IDs synced (`security-cwe-feed.json`).
- Org catalog (`lic/security/cve-catalog.json`): 15 entries.
- **19 Top25 IDs missing**, including CWE-20 (input validation), CWE-79 (XSS), CWE-89 (SQLi), CWE-352 (CSRF).
- `security_cwe_audit` preflight **skipped** (`--skip-slow`) — automated catalog drift detection inactive on fast path.

**Risk:** Swarm cannot self-heal catalog gaps; requires `security_auditor` + human review on catalog PRs.

### 2. Security plan debt routed (medium)

Open registry rows:

- `sec-r1-httpd-fuzz-smoke` — HTTP parse fuzz harness
- `sec-r2-tier5-gap-exploit` — tier5 exploit parity (CWE-20 mitigation in flight via lic PRs)
- `sec-r3-runtime-surface` — runtime attack surface audit

Apply actions patched all three to `security-research-backlog.md` @ 2026-06-07T02:23Z.

### 3. Control-plane observability (medium)

- Observer state/report not persisted before this run (`runs_sampled=0` due to path mismatch).
- Bootstrapped baseline enables dashboard reads; persist-on-tick fix still required in `li-cursor-agents`.

### 4. Preflight / CI blockers (high)

- `org_ci_audit`: GitHub API rate limit — cannot verify 14 repos missing CI.
- 26 open PRs with failing CI including security-adjacent benchmarks UI stack.

## Conclusion

Gap orchestration **mechanism** is healthy after ingest/apply remediation; **security content** gaps (CWE catalog, skipped audits, sec-r* todos) prevent unattended operation. Swarm should remain in supervised mode until `security_auditor` clears catalog drift and CI/preflight blockers drop below grade-C thresholds.
