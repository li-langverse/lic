## Abstract

This pass audits api-coverage for the `swarm_coverage` meta-goal on 2026-06-11. Swarm gap orchestration (registry ingest, backlog apply, handoffs) depends on read APIs that work identically in homelab, K8s org-research Jobs, and CI. Findings: file-based artifacts are mountable and current; MCP `get_briefing_snapshot` works with explicit `benchmarks_root`; gap ingest CLI is blocked on PyYAML; control-plane disk persistence and two MCP read tools remain missing, causing orchestration blind spots that inflate `swarm_execution` scores while gap_pressure stays at 60.
