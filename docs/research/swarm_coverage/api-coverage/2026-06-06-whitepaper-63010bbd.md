## Recommendations

1. **MCP expansion** — expose gap registry + quality report as read-only resources for meta-agents.
2. **Worker image** — bake `python3-yaml` and set default `BENCHMARKS_COMPETITIVE`.
3. **Path parity** — align `LI_RUNS_DIR` / scorecard `runs_dir` with container `/app/data/runs`.
4. **Preflight API hardening** — cache GitHub org repo list; degrade gracefully on 403.
5. **Dispatch order** — `pr_merger` → `ci_maintainer` → `gap_explorer` → `plan_verifier`.
