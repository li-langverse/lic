## Findings

### F1 — Grader blind to runs (`runs_sampled=0`)

Default path `/workspace/li-cursor-agents/data/runs` is empty in org-research worker; actual runs at `/app/data/runs`. Swarm execution dimension stuck at 65 with no error sampling.

**Fix:** Set `LI_CURSOR_AGENTS_ROOT=/app` in worker env; update grader default.

### F2 — Gap ingest API fragility

`swarm-gap-ingest.py:229` had SyntaxError; line 227 raised `KeyError` when `BENCHMARKS_COMPETITIVE` unset. Blocked all vertical stub ingest for 7+ observer cycles.

**Fix:** Merged Path fallback (this run). Bake `python3-yaml` in worker image.

### F3 — Control-plane persistence gap

`state.json` and `latest-report.json` absent — programmatic observer cannot track retry budgets across ticks.

**Fix:** Bootstrap written this run; permanent fix in `build-report.ts` persist hook.

### F4 — MCP reader gaps

No MCP tools for gap registry or quality report — agents must shell/read disk, increasing prompt variance and failure modes.

**Fix:** Add `read_gap_registry` + `read_ecosystem_quality_report` to `li-ecosystem-context`.
