## Abstract

This pass audits API coverage for the `swarm_coverage` meta-goal on 2026-06-11. Swarm gap orchestration (registry ingest, backlog apply, handoffs) depends on read surfaces that work identically in homelab (ops-server REST), K8s org-research Jobs (MCP + file mounts), and CI. Findings: file-backed artifacts are mountable and sufficient for a manual audit, but MCP lacks scorecard/registry readers, control-plane persistence is absent in the Job pod, and PyYAML is missing — blocking gap ingest. The ecosystem grades **C** (76.1) with conditional `unattended_safe: true`.

## Findings

### 1. Headless audit blind spot

Without control-plane disk mirrors, `swarm_execution` scores 100 (0 errors, n=1) while observer self-heal is unobservable. Auditors cannot verify retry budgets or healer dispatch.

### 2. Gap CLI API dependency

```
swarm-gap-ingest: PyYAML required (pip install pyyaml)
```

Programmatic `runSwarmGapIngestTick()` in `src/observer/gap-registry-ingest.ts` fails in this image. Gap registry cannot refresh unattended.

### 3. Briefing enrichment drift

Scorecard recommends `gap_explorer` and `plan_verifier`; briefing heap omits them. Maintenance lane may under-prioritize gap reconciliation.

### 4. Stale goal-directed snapshot

`goal-directed-agents/snapshot.json` dated `2026-05-30`; 6/9 runners stopped. `goal_directed_health` dimension penalized (70.0) but snapshot age not surfaced to agents.

---

## Recommendations

1. Add MCP tools `read_ecosystem_quality_report` and `read_swarm_gap_registry`.
2. Bake `python3-yaml` in org-research worker image.
3. Persist `state.json` + `latest-report.json` on supervisor ticks for Job-pod parity.
4. Union scorecard `recommended_agents` into briefing heap.
5. Route open gaps via existing research goals — no new agent registry ids or systemd plan loops.
