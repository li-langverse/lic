## Abstract

This pass audits Li’s async swarm **gap orchestration pipeline** (registry → ingest → backlog apply → agent handoffs) through a **security** lens. We find the pipeline blocked by orchestration defects (ingest syntax error, missing PyYAML), while security-specific gaps (`sec-r1`–`sec-r3`) remain correctly routed to `security_auditor` but unexecuted. Separately, the MITRE Top-25 CWE feed shows **19 missing catalog rows**, a human-gated backlog item distinct from swarm self-heal.

4. Compared briefing `recommended_agents` vs heap plan for drift.
5. Sampled `/app/data/runs/` for terminal errors.

## Findings

### 1. Gap pipeline availability = security debt velocity

When ingest/apply fails, **plan_debt** rows for `security-research` cannot move from registry to backlog todos. Three todos (`sec-r1` httpd fuzz, `sec-r2` tier5 exploits, `sec-r3` runtime surface) stay **pending** despite prior apply patches in stale `swarm-gap-actions.json`.

**Implication:** Swarm security work is **orchestration-bound**, not agent-bound. Fixing line 229 in `swarm-gap-ingest.py` and baking PyYAML unblocks all gap kinds, including security.

### 2. CWE catalog coverage gap (orthogonal to swarm)

| Metric | Value | Source |
|--------|-------|--------|
| Top-25 CWE feed | 25 ids | `security-cwe-feed.json` |
| Catalog CWE coverage | 15 entries | `cve-catalog.json` |
| Missing in catalog | **19** | feed `top25_missing_in_catalog` |

Briefing correctly elevates `security_auditor`. Catalog expansion requires **human governance** — outside programmatic observer retry budget.

### 3. Control-plane observability

Missing `state.json` / `latest-report.json` prevents dashboards from showing `swarm_degraded` and retry counts. Bootstrapped this pass; persistent write per supervisor tick remains an open `li-cursor-agents` fix.
