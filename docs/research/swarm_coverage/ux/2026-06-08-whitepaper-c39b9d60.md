## Abstract

## Findings (UX)

### F1 — Operator blind spot: `runs_sampled=0`

The quality grader points at `/workspace/li-cursor-agents/data/runs` while org-research writes to `/app/data/runs`. Dashboards show **no terminal run history**, masking error streaks and retry storms.

**Recommendation:** Set `LI_CURSOR_AGENTS_ROOT=/app` on org-research Jobs and in `ecosystem-quality-grade.py` default.

### F2 — Gap pipeline UX: ingest broken, apply invisible

- Ingest: `SyntaxError` at `swarm-gap-ingest.py:229` (remediated this pass).
- Apply: `ModuleNotFoundError: yaml` — no `python3-yaml` / pip in container.
- Last successful apply artifact: `2026-05-31` — operators see **stale** `open_gaps: 64`.

**Recommendation:** Bake PyYAML; surface ingest/apply exit codes on supervisor dashboard.

### F3 — False-open studio-ui plan_debt gaps

Four registry rows (`studio-ux-16`, `-17`, `-21`, `-24`) appear open while loop `completed_ids` includes them. Operators chasing “pending UX todos” waste cycles.

**Recommendation:** `plan_verifier` refreshes `goal-directed-agents/snapshot.json`; ingest closes rows on match.

### F4 — Merge queue cognitive load

637 redundant PR pair warnings (briefing `merge_plan`) create alert fatigue. UX of “what merges next” is good (`lip#52` rank 1) but drowned in noise.
