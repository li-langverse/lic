## Findings

### 1. Org-research Jobs lack REST parity

K8s researcher pods mount benchmarks + lic but not the ops-server. Meta-agents must use MCP or explicit file paths. Missing MCP read tools force brittle path knowledge — a coverage defect for `swarm_coverage`.

### 2. Control-plane persistence API gap

Without `state.json` and `latest-report.json`, the programmatic observer cannot expose `observer.retry_counts` or intervention history. Grade dimension `swarm_execution` reads 100% (0 errors) while orchestration self-heal is **unobservable**.

### 3. Gap ingest CLI blocked on PyYAML

```text
swarm-gap-ingest: PyYAML required (pip install pyyaml)
apt-get install python3-yaml: Unable to locate package
```

Infra API contract failure: ingest dependency not declared in worker image. Apply artifacts remain stale while registry drift may accumulate.

### 4. Orchestration signal drift

| Source | Top recommendations |
|--------|---------------------|
| Briefing heap | `ci_maintainer`, `security_auditor` |
| Scorecard | + `gap_explorer`, `plan_verifier` |

Without a unified API surfacing scorecard `recommended_agents` into briefing heap, gap orchestration agents starve despite 62 open registry rows.

### 5. Preflight read API failures (non-SDK)

- `org_ci_audit` exit 1 — 10 repos HTTP 404.
- `org_agent_kit_audit` exit 1 — `roadmap/agent-kit` not mounted.

Read API failures for briefing consumers; `CURSOR_API_KEY` is set and agent execution is clean.
