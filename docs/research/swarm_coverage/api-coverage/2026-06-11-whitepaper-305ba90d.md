## Abstract

Swarm gap orchestration (registry ingest, backlog apply, handoffs) depends on read APIs that behave identically in homelab, K8s org-research Jobs, and CI. This pass audits api-coverage for the `swarm_coverage` meta-goal and finds REST endpoints complete in `li-cursor-agents` when the ops-server runs, while missing MCP readers, absent control-plane disk persistence, and PyYAML in the worker image block unattended gap refresh and distort operator visibility.
