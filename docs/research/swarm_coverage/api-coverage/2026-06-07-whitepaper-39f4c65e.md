## Abstract

The Li swarm meta-agent (`swarm_observer`) executes a deterministic audit checklist over JSON/YAML artifacts produced by briefing preflight, gap registry ingest, and control-plane observers. This whitepaper maps that checklist to concrete API/file surfaces, measures coverage in the org-research worker as of 2026-06-07, and identifies three blocking gaps that prevent unattended gap orchestration (Mode B).

## Method

1. Regenerated `ecosystem-quality-report.json` via `python3 scripts/ecosystem-quality-grade.py` (benchmarks).
2. Attempted programmatic gap prep: `swarm-gap-ingest.py` → `swarm-gap-apply-actions.py` (lic).
3. Read control-plane state, briefing, registry, and runs catalog.
4. Compared `recommended_agents` (briefing + scorecard) vs `data/runs/` sample.

## Findings

### F1 — Ingest Path API regression

`swarm-gap-ingest.py:229` contains an unterminated string in the `BENCHMARKS_COMPETITIVE` fallback Path expression. This prevents vertical stub discovery and stalls the apply pipeline.

### F2 — PyYAML dependency not in worker image

`swarm-gap-apply-actions.py` requires PyYAML. The org-research container has no `pip`, `apt python3-yaml`, or preinstalled `yaml` module. Backlog patches (sim-algo, package backlog) cannot be applied unattended.

### F3 — Runs directory env contract

`ecosystem-quality-grade.py` defaults `LI_CURSOR_AGENTS_ROOT` to `benchmarks/../li-cursor-agents`, which is absent in the worker mount layout (`/app`). Setting `LI_CURSOR_AGENTS_ROOT=/app` restores run sampling for the swarm_execution dimension.

### F4 — Control-plane persistence gap

Supervisor ticks do not write `data/control-plane/state.json` or `latest-report.json` in the research worker, forcing each meta audit to bootstrap empty state. The programmatic observer cannot track retry budgets across runs.

## Recommendations

1. Merge a single lic PR fixing ingest line 229; close duplicate PRs lic#957–969.
2. Bake `python3-yaml` (or vendor PyYAML) in org-research worker entrypoint.
3. Export `LI_CURSOR_AGENTS_ROOT=/app` in `env.defaults.sh` and briefing preflight wrapper.
4. Add MCP tools `read_gap_registry` and `read_ecosystem_quality_report` to li-ecosystem-context.
5. Enable `LI_CURSOR_AGENTS_ENABLED=1` for deliverable gate in research lane workers.
