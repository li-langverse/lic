## Abstract

The Li swarm gap pipeline (registry → ingest → apply → backlog patch → handoff) depends on filesystem paths and shell scripts that are **partially exposed** to agents. This pass audits **API coverage** for meta-orchestration: which artifacts are reachable via MCP, env defaults, and control-plane persistence. Grade **C** (74.6), `unattended_safe: false`. Primary blockers: PyYAML missing in worker, ingest syntax error (fixed locally), observer state not persisted, MCP missing gap/quality readers.
