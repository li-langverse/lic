## Abstract

Swarm gap orchestration fails the **easy** pillar when operators cannot see health, cannot trust merge queues, and cannot route UX debt through a consistent taxonomy. This pass audits UX signals in the gap registry pipeline, benchmarks dashboard CI noise, and studio-ui plan debt under `swarm_coverage`.

1. Scorecard: `/workspace/benchmarks/data/latest/ecosystem-quality-report.json` (refreshed 2026-06-06).

3. Apply snapshot: `/workspace/benchmarks/data/latest/swarm-gap-actions.json`.
4. Briefing UX failures: GPU chip picker PR cluster in `agent-briefing.json`.
5. Control-plane UX: absence of observer disk artifacts under `/app/data/control-plane/`.

## Findings

### F1 — Operator blind spot (control plane)

Without `latest-report.json` / `state.json`, the org-supervisor dashboard cannot show swarm health, retry budgets, or healer history. Operators re-run meta-audits manually (org-research retry storms in May 2026).

**Severity:** critical for unattended operation.

### F2 — Merge-queue UX debt (benchmarks dashboard)

Eight or more failing PRs duplicate the same GPU chip picker accessibility fix. Redundant-pair warnings (209) increase triage cost and hide the single canonical PR for issue #147.

**Severity:** high — blocks `unattended_safe`.

### F3 — Studio UX plan debt unpatched

`studio-ux-16` (palette search latency) and `studio-ux-17` (GPU fail recovery) remain open in registry. Gap apply cannot patch studio plan todos when `lic-studio-ui` is not mounted.

**Severity:** medium — research lane can still dispatch `gui_ux_tester`.

### F4 — Taxonomy gap: `ui_ux` kind absent

Registry counts: 31 `plan_debt`, 30 `competitor_feature`, 3 `missing_package`, **0 `ui_ux`**. UX issues are misclassified as generic plan debt, weakening `orch-r4-ui-ux-signals` closure criteria.

**Severity:** medium — orchestration fix in ingest, not product code.

## Recommendations

1. **Persist control-plane artifacts** on every org-research Job exit (even when Supabase is down).
2. **Consolidate benchmarks #400–#409** to one WCAG tabs PR; close duplicates.
3. **Mount `LIC_STUDIO_UI_ROOT`** for gap apply; hand off studio-ux-16/17 to `gui_ux_tester`.
4. **Ingest `ui_ux` gap_kind** from preflight ux-audit rows on next gap ingest cycle.
5. **Bake PyYAML** in worker image so ingest/apply runs every supervisor tick.
